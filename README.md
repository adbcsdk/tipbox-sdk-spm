# TipBox SDK (iOS, Swift Package)

- 버전: 1.0.4 (SPM 버전 = git tag)
- 프레임워크는 `Frameworks/` 에 포함(Git LFS).

## 매체 연동
Xcode → Add Package Dependencies → `https://github.com/adbcsdk/tipbox-sdk-spm` → 1.0.4

- NSMotionUsageDescription (만보기)
